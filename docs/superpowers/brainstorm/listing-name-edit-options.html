Listing-name edit affordances

Five ways to signal the name is editable. Each is live — click to try it. Default state is empty ("New listing"), the case where discoverability matters most. Type to see the filled state.

Option A · Pencil CURRENT

Heading + trailing pencil. Tidy, reads as a title. Con: a small icon is easy to miss; not obviously "tap me".

Option B · Hover-reveal

Notion-style. Cleanest at rest; soft hover background + "Rename" appears on hover. Con: hover doesn't exist on touch — weak for a mobile-first marketplace.

Option C · "Rename" chip REC
New listing

Explicit labeled button. Pro: unmistakable on every device, no hover needed. Slightly more visual weight in the header.

Option D · Signposted field

Always a field — dashed underline + faint pencil signal "editable"; underline turns solid violet on focus. Pro: zero clicks to edit. Con: reads less like a page title.

Option E · Inline confirm

Pencil → input with ✓ / ✕. Pro: explicit save + a real cancel-to-revert (the current build has no revert). More controls on screen during edit.
