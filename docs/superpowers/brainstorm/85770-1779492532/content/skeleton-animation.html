Which animation?

A

Pulse — opacity fade

Existing animate-pulse in Tailwind. Already what Skeleton.tsx uses. Calmer, more ambient. Zero new CSS.

B

Shimmer — gradient sweep

Linear gradient moving left to right. More premium feel — the "skeleton screen" pattern you see on Instagram, LinkedIn, YouTube. Requires extending Skeleton.tsx with new CSS + keyframes (and adding a tailwind.config animation entry, or inline-style fallback since this project uses Tailwind v4).
